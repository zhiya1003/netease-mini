## 实际对照到的差别

对照对象不是全屏歌词，而是 Folia Remote 的 594×176 DIP 卡片。使用同一首 Angel、同一封面及同一歌手信息检查收起、展开、无歌词和有歌词状态，并读取 Folia Remote 的 DOM、computed style 与 `remote.css`。

1. 旧版缺少完整的无歌词歌曲卡片：Folia 使用 56 DIP 封面、20/26 歌名、13/19 歌手；sleeve 状态保留歌名/歌手卡片，文字相对普通 line 布局左移 72 DIP。
2. 普通顶行应为 11.5px SemiBold，而不是 13px Bold；标题/歌手墨色分别约为 .84/.46。
3. 副行应为 13/19；Folia 的 remote-second 墨色固定约 .64。
4. 暂停时主歌词 sung ink 约 .62，旧版为 .72。
5. 旧版进度轨道和填充过亮：Folia 展开/收起轨道约 .11/.16；收起填充约 .58，展开为实色。
6. 旧版小图标整排偏白：右上工具默认约 .46，小工具键默认约 .56、激活约 .96，主播放键展开约 .95。
7. 主题回归另发现浅色卡片的时间 Runs 未随主题重着色，导致白字几乎不可见。

## 实现内容

- 新增 `HasLyricLine`，让当前/下一行歌词是否真实存在参与布局选择，而不是只判断 lyric-line 模式。
- 无歌词时使用歌曲卡片；无歌词且 sleeve 时保留大歌名/歌手卡片，并使用 Folia 的 -72 DIP 文字平移。
- 补齐卡片歌名与歌手布局：歌名最多两行、长歌手省略；歌词节点在卡片模式隐藏，歌词出现后恢复歌词布局。
- 按 Folia CSS 校准普通顶行、卡片歌名、歌手、副行、时间、进度条和各组控制图标的字号/墨色。
- 在 `ApplyTheme` 中同步重着色 `timeRun` 与 `timeTotalRun`，修复浅色主题时间白字。
- 保留此前已校准的封面模糊、洗底、展开/退出和歌词渐变节奏，没有改成全屏歌词或另一套卡片。
